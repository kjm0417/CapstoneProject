## 2. 공격 프리팹 만들기 (가장 중요!)

### 2.1 electrode01_0 프리팹 설정

**단계 1: 프리팹 열기**
```
1. Hierarchy에서 electrode01_0 선택
2. Inspector 상단에 "Open Prefab" 버튼 클릭
   (또는 Project 창에서 프리팹 더블클릭)
```

**단계 2: 필수 컴포넌트 추가**
```
electrode01_0 프리팹에 다음 컴포넌트 추가:

1. Collider2D 추가
   - Add Component → Physics 2D → Box Collider 2D
   - Is Trigger: ✅ 체크
   - Size: 이미지 크기에 맞게 조절 (예: 1, 1)

2. Rigidbody2D 추가 (선택사항, 충돌 감지 향상)
   - Add Component → Physics 2D → Rigidbody 2D
   - Body Type: Kinematic
   - Gravity Scale: 0

3. BossAttackObject 스크립트 추가
   - Add Component → Boss Attack Object
   - 자동으로 설정됨 (코드에서 Initialize 호출)
```

**단계 3: 태그 설정**
```
플레이어 오브젝트에 태그 설정:
1. Img_Player 선택
2. Inspector 상단 Tag → Player
   (없으면 Add Tag... → + 버튼 → "Player" 입력)
```

**단계 4: 레이어 설정 (선택사항)**
```
충돌 최적화를 위해:
1. electrode01_0: Layer = "Attack"
2. Img_Player: Layer = "Player"
3. Edit → Project Settings → Physics 2D
   → Layer Collision Matrix에서 설정
```

## 5. 공격 패턴 타입 설명

### 5.1 패턴 종류

| 패턴 타입 | 설명 | 추천 사용 |
|----------|------|----------|
| **Projectile** | 위에서 아래로 떨어짐 | Phase 1 기본 |
| **GroundAOE** | 바닥에 생성되어 정지 | 경고 영역 |
| **WavePattern** | 플레이어 방향으로 이동 | Phase 1-2 |
| **RandomSpawn** | 랜덤 위치에 랜덤 방향 | Phase 2-3 |
| **TrackingHand** | 플레이어 추적 | Phase 2-3 |
| **StraightLine** | 일직선 이동 | Phase 2 |
| **CircularPattern** | 중앙에서 사방으로 | Phase 2 |
| **SpiralPattern** | 회전하며 사방으로 | Phase 3 |

### 5.2 난이도 조절 팁

**쉽게 만들기:**
- Spawn Interval: 3~5초
- Move Speed: 3~5
- Spawn Count: 1
- Time Penalty: 2~3초

**어렵게 만들기:**
- Spawn Interval: 0.5~1.5초
- Move Speed: 6~10
- Spawn Count: 2~5
- Time Penalty: 5~10초

## 6. 테스트 및 디버깅

### 6.1 빠른 테스트 설정

**Phase 1만 테스트하려면:**
```
Phases Size: 1
Element 0 Duration: 10 (10초로 짧게)
```

**특정 패턴만 테스트:**
```
Attack Patterns Size: 1
Element 0: 테스트할 패턴만 설정
Spawn Interval: 1 (빠르게 확인)
```

### 6.2 문제 해결

**공격이 안 나타나요!**
```
✅ Attack Prefab이 설정되었는지 확인
✅ 프리팹에 Collider2D가 있는지 확인
✅ 프리팹에 BossAttackObject 스크립트가 있는지 확인
✅ Console 창에서 에러 메시지 확인
```

**충돌이 안 돼요!**
```
✅ Img_Player에 Tag = "Player" 설정
✅ Collider2D의 Is Trigger 체크
✅ 플레이어에도 Collider2D 있는지 확인
✅ Physics 2D 설정에서 레이어 충돌 확인
```

**공격이 너무 빨라요/느려요!**
```
Move Speed 조절
Spawn Interval 조절
```
