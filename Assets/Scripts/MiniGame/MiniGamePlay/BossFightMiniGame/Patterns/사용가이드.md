# 보스 패턴 시스템 사용 가이드

## 개요

패턴 프리팹을 Phase에 등록하면 자동으로 랜덤 실행되고, 패턴이 끝나면 다음 패턴으로 넘어가는 시스템입니다.

## 1단계: 패턴 프리팹 만들기

### ChargePattern 프리팹 예시

```
ChargePattern (Prefab)
├─ ChargePattern (Script)
│   ├─ Attack Prefab: ChargeAttack
│   ├─ Pattern Duration: 10 (10초 동안 실행)
│   ├─ Spawn Interval: 2 (2초마다 공격)
│   ├─ Time Penalty: 8
│   ├─ Charge Speed: 15
│   ├─ Charge Delay: 0.5
│   └─ Alternate Direction: ✓
```

### ProjectilePattern 프리팹 예시

```
ProjectilePattern (Prefab)
├─ ProjectilePattern (Script)
│   ├─ Attack Prefab: Projectile
│   ├─ Pattern Duration: 8
│   ├─ Spawn Interval: 1.5
│   ├─ Time Penalty: 5
│   ├─ Spawn Count: 3
│   ├─ Move Speed: 5
│   └─ Random X: ✓
```

### CircularPattern 프리팹 예시

```
CircularPattern (Prefab)
├─ CircularPattern (Script)
│   ├─ Attack Prefab: Bullet
│   ├─ Pattern Duration: 12
│   ├─ Spawn Interval: 2
│   ├─ Time Penalty: 4
│   ├─ Bullet Count: 8
│   └─ Move Speed: 5
```

## 2단계: 보스 GameObject 설정

```
BossObject (GameObject)
├─ BossPhaseManager (Script)
│   ├─ Play Area: [PlayArea RectTransform]
│   ├─ Player: [Player RectTransform]
│   ├─ Pattern Container: [자기 자신 또는 별도 Transform]
│   └─ Phases: (리스트)
│       ├─ Phase 1 (0~20초)
│       │   ├─ Phase Name: "Phase 1"
│       │   ├─ Start Time: 0
│       │   ├─ End Time: 20
│       │   └─ Pattern Prefabs:
│       │       ├─ ProjectilePattern
│       │       └─ CircularPattern
│       │
│       ├─ Phase 2 (20~40초)
│       │   ├─ Phase Name: "Phase 2"
│       │   ├─ Start Time: 20
│       │   ├─ End Time: 40
│       │   └─ Pattern Prefabs:
│       │       ├─ ProjectilePattern
│       │       ├─ CircularPattern
│       │       └─ ChargePattern
│       │
│       └─ Phase 3 (40~60초)
│           ├─ Phase Name: "Phase 3"
│           ├─ Start Time: 40
│           ├─ End Time: 60
│           └─ Pattern Prefabs:
│               ├─ ChargePattern
│               ├─ CircularPattern
│               └─ TrackingPattern
```

## 3단계: 보스 시작

```csharp
public class BossFightMiniGame : MiniGameBase
{
    [SerializeField] private BossPhaseManager phaseManager;
    
    protected override void OnStartHook()
    {
        phaseManager.StartBoss();
    }
    
    protected override void OnCleanupHook()
    {
        phaseManager.StopBoss();
    }
}
```

## 동작 방식

### 1. 게임 시작 (0초)
```
→ Phase 1 시작
→ Pattern Prefabs에서 랜덤 선택 (ProjectilePattern 또는 CircularPattern)
→ 선택된 패턴 실행 (예: ProjectilePattern, 8초 동안)
```

### 2. 패턴 실행 중 (0~8초)
```
→ ProjectilePattern이 1.5초마다 발사체 스폰
→ 8초 후 패턴 완료
```

### 3. 패턴 완료 (8초)
```
→ ProjectilePattern 종료
→ 즉시 다음 패턴 랜덤 선택 (CircularPattern)
→ CircularPattern 실행 (12초 동안)
```

### 4. Phase 전환 (20초)
```
→ Phase 2 시작
→ 현재 패턴 강제 종료
→ Phase 2의 패턴 중 랜덤 선택
→ 새 패턴 실행
```

## 패턴 프리팹 만들기 체크리스트

### 1. 빈 GameObject 생성
```
Hierarchy → Create Empty → 이름: "ChargePattern"
```

### 2. 패턴 스크립트 추가
```
Add Component → ChargePattern
```

### 3. Inspector 설정
```
- Attack Prefab: 공격 프리팹 할당
- Pattern Duration: 패턴 지속 시간
- Spawn Interval: 공격 생성 간격
- Time Penalty: 피격 시 시간 감소
- (패턴별 추가 설정)
```

### 4. Prefab으로 저장
```
Hierarchy에서 드래그 → Project 창으로
Assets/Prefabs/BossPatterns/ 폴더에 저장
```

### 5. BossPhaseManager에 등록
```
BossObject 선택 → BossPhaseManager → Phases → Pattern Prefabs에 추가
```

## 새로운 패턴 만들기

### 1. 스크립트 작성

```csharp
using UnityEngine;

public class MyCustomPattern : BossPatternBase

    [Header("커스텀 설정")]
    [SerializeField] private int customValue = 5;

    }
    
    protected override void ExecutePattern()
    {
        // 공격 로직
        Vector2 playerPos = GetPlayerPosition();
        GameObject attack = SpawnAttack(playerPos);
        
        // 추가 처리...
    }
    
    protected override void CompletePattern()
    {
        Debug.Log("커스텀 패턴 완료!");
        base.CompletePattern();
    }
}
```

### 2. 프리팹 생성 및 등록

```
1. 빈 GameObject 생성
2. MyCustomPattern 스크립트 추가
3. Inspector에서 설정
4. Prefab으로 저장
5. BossPhaseManager의 Phase에 추가
```

## 디버깅

### 패턴 실행 확인
```
게임 실행 → 왼쪽 위에 디버그 정보 표시
- Game Time: 현재 시간
- Phase: 현재 페이즈
- Pattern: 현재 실행 중인 패턴
```

### Console 로그
```
[BossPhaseManager] Phase 1 시작!
[ChargePattern] 돌진 패턴 시작!
[ChargePattern] 돌진 패턴 완료!
[BossPhaseManager] 패턴 완료: ChargePattern
[BossPhaseManager] 패턴 시작: CircularPattern
```

## 팁

1. **패턴 지속 시간**: 너무 짧으면 패턴이 자주 바뀌어 혼란스러움 (권장: 8~15초)
2. **패턴 다양성**: Phase당 3~5개 패턴 등록 권장
3. **난이도 조절**: 후반 Phase일수록 어려운 패턴 추가
4. **테스트**: Phase 시간을 짧게 설정해서 빠르게 테스트
5. **프리팹 관리**: `Assets/Prefabs/BossPatterns/` 폴더에 정리

## 문제 해결

### Q: 패턴이 실행되지 않아요
```
A: 
1. BossPhaseManager.StartBoss() 호출 확인
2. Play Area, Player 참조 확인
3. Pattern Prefabs에 프리팹 등록 확인
4. 프리팹에 BossPatternBase 상속 스크립트 확인
```

### Q: 패턴이 바로 끝나요
```
A: Pattern Duration 값 확인 (너무 짧지 않은지)
```

### Q: 같은 패턴만 계속 나와요
```
A: Pattern Prefabs에 여러 패턴 등록 (최소 2개 이상)
```

### Q: Phase가 전환되지 않아요
```
A: Start Time, End Time 겹치지 않게 설정
   Phase 1: 0~20
   Phase 2: 20~40
   Phase 3: 40~60
```
