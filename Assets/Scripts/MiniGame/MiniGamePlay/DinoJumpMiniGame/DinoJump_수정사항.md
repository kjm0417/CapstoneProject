# DinoJumpMiniGame 수정 사항

## 변경된 내용

### 1. 클리어 조건 변경
**기존**: 제한 시간을 버티면 성공  
**변경**: 15개 장애물을 통과하면 클리어

```csharp
[Header("클리어 조건")]
[SerializeField] private int targetObstacleCount = 15; // Inspector에서 조정 가능
```

- 장애물이 플레이어를 지나가면 자동으로 카운트
- UI에 "통과한 수 / 목표 수" 표시 (예: "7 / 15")
- 15개 통과 시 즉시 게임 클리어

### 2. 스트레스 시스템
**시간 초과 후에만 3초당 스트레스 +2** (초당 약 0.67씩 증가)

```csharp
protected override void ApplyStressOverTime(float deltaTime)
{
    // 시간 초과 후에만 스트레스 증가
    if (RemainingTime <= 0f)
    {
        float stressAmount = (2f / 3f) * deltaTime; // 3초당 2
        PlayerManager.Instance.AddStress(stressAmount);
    }
}
```

제한 시간 내에는 스트레스가 증가하지 않고, 시간 초과 후부터 증가합니다.

### 3. 완벽한 클리어(◇) 조건
**조건**: 장애물에 한 번도 충돌하지 않고 15개 통과

- 장애물 충돌 시 `FailPerfectClear()` 호출
- **게임은 계속 진행됨** (실패 처리 안 함)
- 충돌한 장애물은 통과 카운트에서 제외
- 완벽한 클리어 달성 시 Inspector에 설정한 추가 보상 지급

### 4. 시간 제한 처리
**기존**: 시간 종료 시 무조건 성공  
**변경**: 시간 종료 후에도 게임 계속 진행, 스트레스 증가 시작

```csharp
protected override void OnTimeOut()
{
    // 게임을 끝내지 않음 - 계속 진행
    // 스트레스는 ApplyStressOverTime에서 증가 시작
}
```

- 시간 초과 전: 스트레스 증가 없음
- 시간 초과 후: 3초당 스트레스 +2 증가 시작
- 15개 통과할 때까지 게임 계속됨 (충돌해도 계속)

## Inspector 설정 가이드

### DinoJumpMiniGame 컴포넌트

**기본 설정 (MiniGameBase)**
```
Duration: 60 (제한 시간 60초, 필요에 따라 조정)
Stress Per Second: 0.67 (3초당 2)

[성공 보상]
- 스트레스 -10
- 집중력 +5

[실패 보상]
- 스트레스 +15

[완벽한 클리어 보상] ◇
- 스트레스 -5 (추가)
- 집중력 +3 (추가)
- 아이템 획득 (선택)
```

**DinoJump 전용 설정**
```
Target Obstacle Count: 15 (클리어에 필요한 장애물 수)
```

## 게임 플레이 흐름

1. **게임 시작 (0초~60초)**
   - 통과한 장애물: 0 / 15
   - 완벽한 클리어 상태: true
   - 스트레스 증가: 없음

2. **게임 진행 (제한 시간 내)**
   - 장애물이 계속 생성되어 왼쪽으로 이동
   - 플레이어가 점프로 장애물 회피
   - 장애물을 지나칠 때마다 카운트 증가
   - 스트레스 증가 없음

3. **시간 초과 시 (60초 이후)**
   - 게임이 끝나지 않고 계속 진행
   - 스트레스 증가 시작 (3초당 +2)
   - 15개 통과할 때까지 계속

4. **충돌 발생 시**
   - 완벽한 클리어(◇) 실패 처리
   - **게임은 계속 진행** (끝나지 않음)
   - 충돌한 장애물은 카운트에서 제외

5. **15개 통과 시**
   - 즉시 게임 클리어
   - 성공 보상 지급
   - 충돌 없었다면 완벽한 클리어 보상 추가 지급

## 주의사항

1. **PlayerManager.AddStress() 메서드 구현 필요**
   - 현재 주석 처리되어 있음
   - PlayerManager에 스트레스 증가 메서드 추가 필요

2. **장애물 레이어 설정**
   - 장애물 GameObject의 Layer를 "Obstacle"로 설정
   - 바닥은 "Ground" 레이어

3. **UI 텍스트**
   - scoreText에 "통과한 수 / 목표 수" 형식으로 표시
   - 예: "7 / 15"

4. **난이도 조정**
   - Inspector에서 `targetObstacleCount` 값 변경으로 난이도 조절
   - 10개: 쉬움
   - 15개: 보통 (기본값)
   - 20개: 어려움
